# GradPath documentation

The standard project documentation. Documents are in English; documents addressed to Thai
readers are in Thai and end in `.th.md`.

| Document | Purpose |
|---|---|
| [requirements.md](requirements.md) | What GradPath must do, acceptance conditions, scope and change log |
| [architecture.md](architecture.md) | Components, state machine, data contracts, tools, planner, failure semantics |
| [decisions.md](decisions.md) | Architecture decision records |
| [plan.md](plan.md) | Schedule to 11 Nov 2026, MVP scope for UAT, risks and cut lines |
| [evaluation.md](evaluation.md) | Test set format and quality bar, experiment arms, metrics, UAT design |
| [dev-setup.md](dev-setup.md) | Development environment and known pitfalls |
| [status.md](status.md) | Progress log |

Evidence behind pitch v9: `baseline/results/slide_ready.md`.

## Conventions

- Dates are absolute (for example 4 Nov 2026), in Bangkok time.
- Data status labels: `verified` (official source), `inferred` (derived or unofficial
  source), `unknown` (not found), `conflict` (sources disagree).
- A decision changes only through a new or amended entry in `decisions.md`.
- Update `status.md` when a milestone is reached or the plan changes.
